# Система

> Сводное межуровневое представление Aveli.

## Статус

**Базовая версия: стабильна**

Системная базовая версия объединяет стабильные представления бизнеса, данных, бэкенда, фронтенда и интеграций.

Оставшиеся неблокирующие вопросы явно классифицированы в реестре закрытия, а не оставлены в виде неоднозначных архитектурных предположений.

## Назначение

`system/` владеет моделями, которые описывают сразу несколько компонентов:

```text
системный контекст
связи компонентов
сценарии выполнения
границы доверия
перемещение данных
межкомпонентные инварианты
изменения, затрагивающие границы системы
сводные сценарии отказов и готовности к релизу
реестр закрытия вопросов
```

## Общая форма системы

```text
Независимый специалист
        ↓
Мобильный клиент Aveli
   ├── Локальное профессиональное рабочее пространство
   │      ↓
   │  SQLite + файлы
   │
   └── API аккаунта и доступа
          ↓
      Бэкенд Aveli
          ↓
      PostgreSQL
          ↕
      RevenueCat
          ↕
 Apple App Store / Google Play
```
