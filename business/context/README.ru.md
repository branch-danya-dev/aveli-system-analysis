# Context

> Контекст продукта, целевые пользователи, цели и позиционирование Aveli.

---

## Назначение

Директория `context/` объясняет **зачем существует Aveli, для кого создан продукт и какую пользовательскую проблему он должен решать**.

Эта область задает бизнес-контекст, необходимый перед чтением scope, требований и технической документации.

---

## Ответственность

Область отвечает за:

- назначение продукта;
- целевых пользователей;
- пользовательские проблемы и потребности;
- позиционирование продукта;
- продуктовые цели и направление успеха;
- верхнеуровневые продуктовые принципы.

---

## Границы

Context объясняет **почему существует продукт**.

Здесь не следует описывать подробное функциональное поведение, техническую архитектуру, технологии, структуру БД или API contracts.

Подробные продуктовые границы относятся к `../scope/`.

Подробное поведение — к `../requirements/` и `../processes/`.
