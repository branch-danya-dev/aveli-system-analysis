# Drift

> Типизированная технология доступа Flutter к данным поверх локального рабочего пространства SQLite на устройстве.

## Подтверждённая версия

`drift 2.34.3`

## Роль

```text
Репозитории Flutter
      ↓
Drift
      ↓
SQLite
```

В текущей реализации Drift используется для объявления схемы и таблиц, типизированных запросов и сгенерированных вспомогательных классов, версионирования схемы и миграций, реактивного чтения через `.watch()`, обновления таблиц, генерации кода базы данных и тестирования на базе данных в памяти.

Каноническая физическая модель: [`../../../database/local/`](../../../database/local/)

## Заменяемость

**Средняя.** Замена Drift при сохранении SQLite затронет реализации репозиториев, сгенерированные модели и вспомогательные классы, реактивное чтение, инструменты миграций и тесты базы данных.

Ближайшие альтернативы — ориентированные на SQLite слои доступа, например `sqflite` с ручным SQL или Floor. Переход на нереляционное хранилище означал бы уже изменение модели хранения, а не только замену слоя доступа к данным.
