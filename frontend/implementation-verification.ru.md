# Проверка реализации фронтенда

> Итоговый результат сверки документации с текущим клиентом Flutter.

## Статус

**Применено — базовая версия фронтенда стабильна**

Подтверждённая базовая версия: Aveli `0.2.2+4`, Dart `^3.7.0`, гибридная архитектура с организацией по функциональным областям, Riverpod 2.6.1, go_router 14.8.1 и Drift 2.34.3.

## Внесённые уточнения

- вспомогательный механизм привязки устаревшей `aveli.db` существует, но текущий пользовательский интерфейс его не вызывает;
- `CustomerInfo` RevenueCat не открывает рабочее пространство напрямую;
- срок следующей проверки, переданный сервером, имеет приоритет; 72 часа остаются клиентским значением по умолчанию там, где это применимо;
- выход из аккаунта сохраняет SQLite и фотографии, а явное удаление профиля выполняет локальную разрушительную очистку;
- выход со всех устройств существует на бэкенде, но текущий клиент на Flutter и интерфейс его не предоставляют;
- маршруты подтверждения электронной почты и сброса пароля на бэкенде пока являются заглушками с ответом 501;
- подтверждённое дерево исходного кода включает `legal/` и `more/`;
- канонический владелец документации Drift — `frontend/stack/drift/`.

## Классифицированные неблокирующие вопросы

| Вопрос | Классификация |
|---|---|
| Поведение резервного копирования Android | Политика платформы не подтверждена; утверждение в базовую версию не включено. |
| Закрепление сертификата | Не входит в текущую модель безопасности; пересматривается только при изменении модели угроз. |
| Проверка прав суперпользователя или признаков джейлбрейка | Не входит в текущую модель безопасности; пересматривается только при изменении модели угроз. |
| Производственные идентификаторы продуктов магазинов | Внешняя конфигурация релиза. |
| Интерфейс работы с несколькими аккаунтами | Вне текущих границ продукта; одновременно активен один аккаунт и одно рабочее пространство. |
| Гарантия восстановления напоминаний после перезагрузки | Ограничение контроля качества платформы и производителя устройства; обработчик загрузки существует, а перестроение при возврате в приложение подтверждено. |
| Результат полного прогона тестов | Подтверждение конкретного релиза, а не архитектурный факт. |
| Сквозные покупки через реальные магазины | Будущее подтверждение релиза. |
| Интерфейс привязки устаревшей базы данных | Вне текущего пользовательского сценария до появления отдельной функции миграции. |

Ни один из перечисленных вопросов не блокирует стабильную архитектурную базовую версию фронтенда.
