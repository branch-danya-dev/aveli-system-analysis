# `app_settings`

> Хранение локальных настроек в формате «ключ — значение».

| Столбец | Тип | NULL | Назначение |
|---|---|---|---|
| `key` | TEXT | NO | Первичный ключ; ключ настройки. |
| `value` | TEXT | NO | Сериализованное значение настройки. |

## Известные ключи

| Ключ | Формат | Назначение |
|---|---|---|
| `themeId` | имя перечисления (`enum`) | Тема оформления. |
| `profileName` | string | Имя специалиста. |
| `profilePhone` | string | Телефон. |
| `profileEmail` | string | Электронная почта локального профиля интерфейса. |
| `profileSpecialization` | string | Специализация. |
| `profileStudioName` | string | Название студии. |
| `profilePublicSlug` | string | Публичный идентификатор (`slug`). |
| `profileCurrencyCode` | ISO 4217 | Рабочая валюта; по умолчанию RUB. |
| `currencyDefaultRubV1` | `'1'` | Признак миграции EUR → RUB. |
| `profileLocaleCode` | string | Локаль; по умолчанию `ru`. |
| `profileAccountLifecycle` | имя в хранилище | Локальное состояние жизненного цикла аккаунта в интерфейсе. |
| `profilePhoneVerified` | `'1'` / `'0'` | Локальный признак подтверждения телефона в интерфейсе. |
| `profileEmailVerified` | `'1'` / `'0'` | Локальный признак подтверждения электронной почты в интерфейсе. |
| `profilePublicListing` | имя в хранилище | Состояние публичной публикации профиля. |
| `visitRemindersEnabled` | `'1'` / `'0'` | Локальные напоминания; по умолчанию включены. |
| `scheduleWorkingStartMinutes` | строка с целым числом | Начало рабочего дня. |
| `scheduleWorkingEndMinutes` | строка с целым числом | Конец рабочего дня. |
| `exchangeRateCacheV1` | JSON | Кэш курса валют. |

Значения профиля в этой таблице относятся к локальным настройкам интерфейса и не являются зеркалом серверной таблицы `users`.
