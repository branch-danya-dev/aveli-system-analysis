# Conceptual Data Model

> Technology-independent представление основных information concepts Aveli.

## Назначение

Область объясняет **какие информационные концепции существуют и как они связаны**, не рассматривая их как database tables.

Здесь не размещаются SQL types, implementation table names, indexes, ORM annotations, migration details или storage-specific fields.
