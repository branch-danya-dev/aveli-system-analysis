# Концептуальная модель данных

> Технологически независимое представление основных информационных понятий Aveli.

## Назначение

Область объясняет, **какие информационные понятия существуют и как они связаны**, не рассматривая их как конкретные таблицы базы данных.

Здесь не размещаются типы SQL, физические имена таблиц, индексы, аннотации ORM, детали миграций или поля, специфичные для конкретного хранилища.
