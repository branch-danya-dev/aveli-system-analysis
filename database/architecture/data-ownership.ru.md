# Aveli — владение данными

> Канонические границы владения данными и источников истины в Aveli.

## Основная граница

```text
Профессиональное рабочее пространство
        ↓
Рабочее пространство пользователя

Идентификация и доступ
        ↓
      Бэкенд
```

Домены связаны механизмом контроля доступа, но владение данными у них раздельное.

> **Данные профессиональной деятельности принадлежат изолированному рабочему пространству пользователя. Идентификация и состояние доступа принадлежат домену аккаунта, управляемому бэкендом.**

Граница следует из `BR-020`–`BR-026` и `BR-043`–`BR-047`.

## Домен профессионального рабочего пространства

| Данные | Канонический владелец |
|---|---|
| Клиенты | Профессиональное рабочее пространство |
| Услуги | Профессиональное рабочее пространство |
| Записи | Профессиональное рабочее пространство |
| Оплаты | Профессиональное рабочее пространство |
| Заметки визитов | Профессиональное рабочее пространство |
| Фотографии визитов / материалы рабочего пространства | Профессиональное рабочее пространство |

Текущая модель продукта не делает бэкенд Aveli источником истины для этих записей.

Данные рабочих пространств изолированы по пользователям. Данные одного рабочего пространства не должны становиться видимыми при активном рабочем пространстве другого пользователя.

## Домен идентификации и доступа

| Данные | Канонический владелец |
|---|---|
| Идентификатор и состояние аккаунта | Бэкенд |
| Полномочия аутентифицированной сессии | Бэкенд |
| Состояние пробного периода | Бэкенд |
| Ручные права доступа | Бэкенд |
| Бессрочный доступ | Бэкенд |
| Определённое состояние подписки | Бэкенд |
| Итоговое решение о доступе к рабочему пространству | Бэкенд |

Сведения о подписке могут поступать из экосистемы мобильного биллинга, но итоговое решение о доступе к рабочему пространству остаётся ответственностью бэкенда Aveli.

## Доступ не владеет данными рабочего пространства

```text
Доступ действует → рабочее пространство доступно
Доступа нет      → рабочее пространство недоступно
                   ↓
                 Сохранённые данные не изменяются
```

Истечение доступа не должно удалять или изменять сохранённые данные профессионального рабочего пространства.

## Выход и смена аккаунта

Выход завершает активное аутентифицированное состояние, но не удаляет сохранённое рабочее пространство.

Смена аккаунта меняет активный контекст рабочего пространства, но не переносит данные между рабочими пространствами.

## Внешние источники данных

Внешнее происхождение данных не делает внешнюю систему владельцем результирующей записи Aveli. Например, импорт контакта устройства создает или дополняет запись клиента Aveli, но исходный контакт не становится владельцем этой записи.

## Функции, меняющие границу

Модель нужно пересмотреть при появлении:
- синхронизация рабочего пространства между устройствами;
- облачное резервное копирование рабочего пространства;
- публичная запись с серверным хранением профессиональных данных;
- общие или совместные рабочие пространства.
