# Интеграции

> Каноническая документация внешних границ Aveli: провайдеры, магазины приложений, возможности ОС и сторонние API.

## Статус

**Базовая версия: стабильна**

Базовая версия интеграций сверена с подтверждениями из Flutter, бэкенда и нативных конфигураций. Факты, доступные только в панелях провайдеров или зависящие от конкретного устройства и производителя, классифицируются как внешние подтверждения для релиза и контроля качества, а не как скрытые архитектурные предположения.

## Ландшафт внешних интеграций

| Интеграция | Роль |
|---|---|
| RevenueCat | Абстракция подписки, покупка и восстановление, серверная сверка и вебхуки. |
| Apple App Store | Биллинг и управление подпиской на iOS. |
| Google Play | Биллинг и управление подпиской на Android. |
| Контакты устройства | Импорт контактов в Aveli только для чтения. |
| Уведомления устройства | Локальные напоминания о записях и переход из уведомления. |
| Медиа устройства | Камера и галерея как источник фотографий визитов. |
| API курсов валют | Получение курсов для локального пересчёта валют. |
| Передача управления устройству | SMS, системное меню «Поделиться», выбор файла и ссылки управления подпиской. |

Flutter ↔ бэкенд Aveli — внутренний интерфейс системы, а не внешняя интеграция. Канонические контракты находятся в [`../backend/api/`](../backend/api/).

Проверка реализации: [`implementation-verification.ru.md`](implementation-verification.ru.md)
