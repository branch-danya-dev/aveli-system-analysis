# Данные, пересекающие внешние границы

| Направление | Данные | Авторитетный источник | Хранение в Aveli | Чувствительность |
|---|---|---|---|---|
| Мобильный клиент Aveli → SDK RevenueCat | Серверный UUID пользователя Aveli | Система идентичности Aveli | Идентификатор пользователя RevenueCat | Средняя |
| Apple App Store / Google Play → RevenueCat | Подтверждения жизненного цикла покупки и подписки | Магазин приложений | Состояние у провайдера | Средняя |
| RevenueCat → бэкенд Aveli | JSON права доступа и подписки | Подтверждения RevenueCat | `subscriptions` | Средняя |
| Вебхук RevenueCat → бэкенд Aveli | Метаданные события и очищенная полезная нагрузка | RevenueCat | `subscription_events` | Средняя |
| Контакты устройства → фронтенд | Имя, телефон, идентификатор контакта | Устройство пользователя | Drift `clients` | Персональные данные |
| Фронтенд → уведомления ОС | Заголовок, текст, идентификатор записи | Намерение планировщика Aveli | Планировщик ОС | Низкая |
| Камера / галерея → фронтенд | Выбранное изображение | Пользователь / устройство | Скопированный файл и метаданные БД | Персональные данные |
| API курсов валют → фронтенд | Курсы валют | Сторонний провайдер | Кэш `app_settings` | Низкая |
| Фронтенд → приложение SMS | Телефон и текст сообщения | Пользователь принимает решение об отправке | Не хранится | Персональные данные |
| Фронтенд → системное меню «Поделиться» | Экспортированный файл JSON | Пользователь выбирает получателя | Временный файл | Персональные данные |
| ОС → фронтенд | Типы подключения | Только сигнал ОС | Только поток событий | Низкая |

Внешние данные авторитетны только в пределах фактов, которыми владеет их источник. Магазин приложений и RevenueCat подтверждают состояние биллинга, а решение о доступе к рабочему пространству принимает бэкенд Aveli. Сигнал о подключении — лишь подсказка, а не доказательство доступности бэкенда. После импорта контакт становится отдельной локальной записью клиента, принадлежащей рабочему пространству Aveli.
