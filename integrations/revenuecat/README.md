# RevenueCat Integration

> Cross-component subscription integration connecting Aveli Mobile, Aveli Backend, RevenueCat, and the mobile stores.

## Purpose

RevenueCat is Aveli's store-subscription abstraction layer.

It supports:

- mobile offerings;
- purchase;
- restore;
- customer identity;
- server subscriber lookup;
- webhook-driven lifecycle reconciliation.

RevenueCat is **not** the final Aveli workspace-access authority.
